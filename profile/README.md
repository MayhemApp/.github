# Mayhem
## Chaotic chatting app
meant for fun lol  
small project that is made and updated by 4 people  

## what do we do?  
we're a small discord competitor packed with features and way less restrictive than discord  
- free for everyone  
- longer messages  
- less restrictive limits  

## do we have a "premium" tier?  
yes, for some small benefits so we can expand our reach and improve our services for everyone  
you will get:
- exclusive supporter badge and tag
- higher quality streaming
- more profile customisation: custom banner
- increased server limit (200 -> 500)
- higher upload size per file (25MB -> 100MB)
